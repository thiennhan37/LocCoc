Mở hồ sơ trong LocCoc

Nếu đã cài ứng dụng, hãy chạm vào link hồ sơ bạn nhận được trong tin nhắn để mở trang cá nhân.

Nếu điện thoại chưa mở ứng dụng, hãy kiểm tra bạn đang dùng bản LocCoc hỗ trợ link hồ sơ.

Mở link chỉ để xem hồ sơ. Bạn chủ động nhấn “Kết bạn” trong ứng dụng để gửi lời mời.
