# English image query and fuzzy original text

Implement ADR-022 without changing public endpoint paths or image embedding profiles.

1. Mobile posts the unchanged trimmed query and filters. On successful explicit search, scroll the result list to the start; preserve controller selection and reject stale request effects.
2. Post resolves temporal expressions once and supplies that same original-language content to the text branch. Python receives only the visual content plus authoritative owner/date/album/place filters.
3. `QUERY_TRANSLATION_ENABLED=true` by default; `GEMINI_QUERY_TRANSLATION_MODEL=gemini-3.1-flash-lite`. Translate through the existing dedicated embedding client using schema-constrained output. Versioned owner-scoped cache: 512 entries, 900 seconds. Completed-query cache precedes translation and coalesces identical requests. Translation plus embedding consume up to two query-budget reservations on a cold query; no automatic retries or budget increases. Disable translation explicitly for rollback. Translation timeout/model/output failures fall back to embedding the original query; cache that result for 30 seconds. Hard quota/Redis failures remain closed. Post falls back to metadata only when image retrieval itself fails; requireSemantic remains strict. Internal search deadline is 9 seconds, Java 10 seconds, below gateway 15 seconds.
4. Text normalization: NFC/NFD accent folding including đ, lowercase, Unicode letter/digit tokens. Require exact match for tokens shorter than four characters; longer words allow one edit (two for eight or more characters) with transposition support. Require all query tokens, matched to distinct text tokens in a bounded contiguous window; rank exact phrases above fuzzy matches. Keep date/owner/state/managed-image filters for every page and rehydrate final candidates.
5. Test 33-photo pagination independently from this search change. Run Python provider/security tests, Java text/search/protocol tests, Flutter Moments tests and focused analyzers. Do not call paid provider APIs to run unit tests.
6. Local IDE/Maven Post launches inherit only missing `SEMANTIC_SEARCH_ENABLED`, `AI_SERVICE_TOKEN`, `AI_ACTOR_SECRET`, `EMBEDDING_DIM` from sibling AI `.env`, like the Node launcher. Explicit/blank settings win. Production profiles or `post.local-ai-config-enabled=false` skip local inheritance. Do not import provider keys/budgets. Caption-only results report a safe failure reason and Mobile distinguishes missing metadata matches from a completed image search.
